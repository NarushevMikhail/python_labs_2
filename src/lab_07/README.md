# Лабораторная работа 7 
## 1. Что было сделанно в этой лабе?
* В ходе лабораторной работы реализовано консольное `CLI-приложение` для управления пользователями с поддержкой операций: создание, просмотр всех, поиск по никнейму, удаление, сортировка по никнейму и логину, а также вывод статистики. 
* Данные сохраняются в `JSON-файл` и загружаются при запуске, что обеспечивает их сохранность между сеансами работы. 
* Применены навыки объектно-ориентированного программирования: созданы классы `CLI, Application, Storage, UserList и User` с инкапсуляцией, приватными атрибутами, свойствами property для валидации, декораторами и наследованием. 
* Реализована собственная иерархия исключений. Код разделен на модули: `main.py` — точка входа, `cli.py` отвечает за интерфейс и меню, `app.py` содержит бизнес-логику, `storage.py` — загрузку и сохранение в JSON, `exceptions.py` — пользовательские исключения. Применена обработка ошибок с `try-except`, валидация входных данных, работа с файловой системой, импорты из других лабораторных работ, а также методы работы с коллекциями: сортировка, поиск, фильтрация.

## 2. Структура работы. 
* ```main.py``` — точка входа в приложение. Этот файл запускается первым, он создает экземпляры классов Storage, Application и CLI, связывает их между собой и запускает приложение вызовом метода start().

* ```cli.py``` — отвечает за пользовательский интерфейс. Здесь реализован класс CLI, который показывает меню, запрашивает ввод от пользователя, выводит результаты на экран и обрабатывает некорректный ввод. Этот файл только взаимодействует с пользователем, но не содержит бизнес-логики.

* ```app.py``` — содержит бизнес-логику приложения. Класс Application управляет коллекцией пользователей, выполняет проверки при добавлении (уникальность логина, длина пароля, допустимость роли), осуществляет поиск, удаление, сортировку и вызывает сохранение данных через Storage.

* ```storage.py``` — отвечает за сохранение и загрузку данных. Класс Storage преобразует объекты пользователей в словари, сохраняет их в JSON-файл в папку data, а при загрузке читает файл и возвращает список словарей для восстановления объектов.

* ```exceptions.py``` — содержит собственные исключения приложения. Здесь определены классы ValidationError для ошибок валидации, NotFoundError для случаев когда пользователь не найден, DuplicateError для дубликатов и StorageError для ошибок при работе с файлом.


## 3. Описание ```cli.py```
### 1. Реализованые пукнуты меню: 
1. Создать пользователя — запрашивает никнейм, логин, пароль и роль. Перед добавлением проверяет уникальность никнейма и логина, длину пароля (минимум 6 символов), наличие цифры в пароле, допустимость роли (user, admin, moderator). При успехе пользователь сохраняется в коллекцию и в файл.

2. Показать всех пользователей — выводит список всех зарегистрированных пользователей с их никнеймами, логинами и ролями. Если пользователей нет, выводится соответствующее сообщение.

3. Найти пользователя по никнейму — запрашивает никнейм и выводит информацию о найденном пользователе. Если пользователь не найден, выводится сообщение об ошибке.

4. Удалить пользователя — запрашивает никнейм, показывает найденного пользователя и запрашивает подтверждение. После подтверждения удаляет пользователя из коллекции и обновляет файл.

5. Сортировка — предлагает сортировку по никнейму или по логину. Пользователь выбирает направление сортировки (по возрастанию или убыванию), после чего выводится отсортированный список.

6. Статистика — выводит общее количество пользователей и количество администраторов, модераторов и обычных пользователей.

7. Выход — завершает работу приложения.

### 2. `Обработка ошибок ввода`

* При некорректном вводе программа не вылетает, а обрабатывает ошибку и продолжает работу:

* Ввод числа вместо строки в меню — используется конструкция try-except, которая ловит ValueError и выводит сообщение "Ошибка: введите число", после чего меню показывается снова.

* Пустые значения при создании пользователя — проверяются через if not nickname, вызывается ValidationError с сообщением о необходимости заполнить поле.

* Некорректный выбор пункта меню — если пользователь ввел число вне диапазона от 0 до 5, выводится сообщение "Неверный выбор" и меню повторяется.

* Ошибки валидации данных — все проверки никнейма, логина, пароля и роли обернуты в try-except, который ловит ValidationError, DuplicateError и выводит понятное пользователю сообщение без остановки программы.

* Поиск несуществующего пользователя — метод find_user_by_nickname возвращает NotFoundError, который перехватывается и выводится сообщение "Пользователь не найден".

### 3. `Сохранение работает следующим образом:`

1. При добавлении, удалении или обновлении пользователя автоматически вызывается метод `_save_data()` в `app.py`, который обращается к `storage.py.` В `storage.py` метод `save()` получает список всех пользователей из коллекции, затем для каждого объекта User создает словарь с полями `nickname, login, password, role,` а также дополнительными полями bio, age, city, если они есть. Затем используется json.dump() с параметрами indent=2 для читаемого форматирования и ensure_ascii=False для поддержки русского языка. Файл сохраняется в папку data с именем `users.json.`

### 4. `Загрузка работает следующим образом:`

* При запуске приложения в конструкторе Application вызывается метод _load_data(). Он обращается к storage.py, где метод load() проверяет существование файла users.json. Если файл существует, он открывается на чтение, и json.load() преобразует содержимое файла обратно в список словарей. Затем для каждого словаря создается объект User с помощью конструктора User(nickname, login, password, role), и этот объект добавляется в коллекцию UserList. Если файл не существует, метод load() возвращает пустой список, и приложение запускается с пустой коллекцией.

### 5. `Дополнительные особенности:`

* Папка data создается автоматически при инициализации Storage с помощью `mkdir(exist_ok=True)`

* При возникновении ошибки при сохранении или загрузке выбрасывается собственное исключение `StorageError`, которое перехватывается и выводит понятное сообщение
